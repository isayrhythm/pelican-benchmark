## 生成方式

每一份作品都在纯净的新对话中提交同一条 Prompt 生成，不复用此前的聊天记录或其他作品的对话上下文。

新对话不代表各平台的系统提示词、Harness 配置和内置工具完全一致。因此，作品分别标记模型、运行工具（Harness）和服务平台。Dot 是 OpenAI 的个人助手，不是底层模型名称。

这是作品展示集，不提供自动评分或模型排名。

## Prompt

> 不要联网，全靠你自己创建一个 HTML，内容是 SVG 绘制一个鹈鹕骑自行车的 2D 动画。你不需要任何测试，确认创建，无需询问我。
